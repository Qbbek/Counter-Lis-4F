# .NET MAUI Counter

Prosta aplikacja wieloplatformowa typu "Counter" napisana w .NET MAUI, służąca do zarządzania wieloma licznikami z poziomu interfejsu graficznego.

## Funkcjonalności i spełnione wymagania

- **Dynamiczne liczniki:** Możliwość dodawania nieograniczonej liczby liczników z własnymi nazwami.
- **Wartość początkowa:** Umożliwia zdefiniowanie początkowej wartości licznika w momencie jego tworzenia.
- **Modyfikacja stanu:** Przyciski zwiększania (+), zmniejszania (-), resetowania (Reset) oraz usuwania (Delete) dla każdego licznika.
- **Trwałość danych (pliki tekstowe):** Automatyczny zapis stanu każdego licznika do osobnego pliku `.counter.txt` w katalogu aplikacji przy każdej zmianie oraz odczyt przy uruchamianiu.

## Technologie

- C# / .NET MAUI 9.0
- LINQ do wczytywania i sortowania liczników
- Data binding w XAML
